# Админка «КОРОЛИ ДОРОГ»

HTML/CSS/JavaScript-панель для общей базы заказов и водителей NestJS API.

Самый простой совместный запуск — Docker Compose из корня проекта: см. [README](../README.md). Админка и API используют один адрес, nginx проксирует `/api/` и `/socket.io/`.

## Отдельный запуск

Подойдёт любой статический сервер, например:

```sh
python -m http.server 8080 --directory admin
```

Откройте `http://localhost:8080`, укажите адрес API на экране входа. Принимаются адрес хоста и адрес с `/api`; лишний префикс не добавляется. Для локального API по умолчанию используется `http://127.0.0.1:3000/api`. На внешнем хосте по умолчанию выбирается `/api` того же сервера.

Логин и пароль задаются через `ADMIN_LOGIN` и `ADMIN_PASSWORD` API. Для HTTPS-страницы нужен HTTPS API. При другом домене добавьте точный адрес админки в `CORS_ORIGINS` сервера. Смена сервера сбрасывает токен предыдущего подключения.

## Возможности

Дашборд, диспетчерская, проверка документов, поддержка, рассылки, водители, клиенты, заказы, финансы, тарифы, промокоды, журнал и настройки. Диспетчерская обновляется раз в 15 секунд после окончания предыдущего запроса; фоновые вкладки не обновляются. Статус соединения показан в верхней панели.

Карты: Yandex с ключом JavaScript API или OpenStreetMap/Leaflet. Ключ задаётся в настройках панели. Без сети или GPS показан явный запасной интерфейс. MapKit-ключ мобильного приложения и JavaScript-ключ админки — разные настройки.

Проверки документов доступны администратору; публичный аватар водителя не подменяется его паспортом или селфи проверки.

## Проверка

```sh
cd admin
npm ci
npm test
npx playwright install chromium
npm run test:ui
```

Браузерный тест проверяет вход, диспетчерскую, модальные окна, переходы, выход и ширину 390 px. Все данные синтетические, результаты находятся в `../artifacts/`.
